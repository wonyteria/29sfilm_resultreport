# 결과보고 항목별 자동화·직접 입력 기준

## 원칙

프로그램은 문서와 자료에서 값을 `추출·제안`하고 담당자가 사실값을 `확정`한다. 숫자, 날짜, 인명은 자료에서 읽혔더라도 자동 확정하지 않는다. 직접 입력이 필요한 페이지는 완전히 빈 슬라이드로 두기보다, 승인 템플릿과 항목명·누락 상태를 넣은 검수용 페이지로 생성한다.

## 항목별 처리 방식

| 결과보고 항목 | 권장 근거 폴더 | 프로그램 역할 | 담당자 역할 | 자료 없을 때 |
|---|---|---|---|---|
| 사업명·주최·주관·기간·목적·주제 | 01.최종기획안 | 최종 문서에서 후보 추출 | 기준 문서와 값 확정 | 입력 폼 제시 |
| 전체 일정표 | 01.최종기획안 | 일정표 추출·정규화 | 실제 일정 변경 확인 | 일정 입력 표 제시 |
| 홍보 채널·기간·실적 | 03~05 홍보 폴더 | 채널 분류, 리포트 우선 추출, 캡처 OCR | 최종 수치와 기준일 확정 | 해당 없음/자료 요청 선택 |
| 출품 현황 | 06.출품현황 | Excel 집계 또는 캡처 OCR, 합계 검사 | 최종·부문별 수치 확정 | 입력 표와 누락 경고 |
| 심사 일정·방식·심사위원 | 07.심사 | 최종 심사기획안에서 추출 | 최종 변경과 명단 확정 | 입력 폼 제시 |
| 수상자·수상작 | 08.수상작 | 입력 표, 이미지·URL 연결, 중복·누락 검사 | 직접 입력·확정 | 검수용 빈 수상작 페이지 |
| 시상식 개요·큐시트 | 09.시상식및결과발표 | 최종 시상식기획안과 큐시트에서 추출 | 실제 운영 변경 확정 | 시상식 없음/자료 요청 선택 |
| 참석자·현장 사진·후기 | 10.참석자및후기 | 사진 후보와 후기 후보 정리 | 참석자·캡션·채택 후기 직접 확정 | 검수용 빈 페이지 또는 모듈 제외 |
| 최종 총평 | 11.성과및총평 및 전체 확정값 | AI 1차 초안, 근거 연결, 변경 영향 표시 | 수정·승인 | 임시 초안과 미반영 항목 표시 |

## 문서 선택 규칙

- 파일명에 `최종`, `승인`, `확정`이 있으면 우선 후보로 제안한다.
- 파일명만으로 자동 확정하지 않는다.
- 여러 최종본이 있으면 수정일과 버전을 보여주고 담당자가 하나를 선택한다.
- 문서에 계획 수치와 실적 수치가 함께 있으면 `계획`과 `실적`을 구분한다.
- 기획안의 일정과 실제 집행 증빙의 날짜가 다르면 실제 여부를 담당자에게 묻는다.

## 구조화 자료 우선순위

1. 담당자가 확정한 프로그램 입력값
2. 승인된 XLSX·CSV 리포트
3. 승인된 최종 기획안·큐시트
4. PDF 리포트
5. 화면 캡처 OCR
6. 파일명과 폴더명 추정

낮은 우선순위 자료가 높은 우선순위 값을 자동으로 덮어쓰지 않는다.

## 자료 없는 페이지 표현

초안에서는 다음 중 하나를 적용한다.

- `입력 대기`: 담당자가 직접 작성할 필수 페이지
- `자료 대기`: 자료를 받아야 작성할 페이지
- `확인 필요`: 자동 추출 후보가 있으나 미확정인 페이지
- `해당 없음`: 담당자가 활동 없음으로 확정해 제외할 페이지

빈 흰색 페이지는 무엇이 빠졌는지 알기 어렵기 때문에 사용하지 않는다. 검수용 상태 표시는 완성본 확정 시 자동 제거한다.
