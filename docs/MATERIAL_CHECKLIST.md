# 결과보고서 자료 준비 체크리스트

## 공통 원칙

- 실제 집행·확정된 최종본을 넣는다.
- 같은 문서가 여러 개면 파일명에 `최종`, 버전 또는 날짜를 표시한다.
- 캡처만 저장하기보다 가능하면 XLSX·CSV·PDF 원본 리포트도 함께 넣는다.
- 날짜, 매체명, 회차를 파일명에 포함한다.
- 보고서에 사용할 대표 이미지는 `00.대표사진` 폴더에 별도로 모은다.
- 실행하지 않은 항목은 빈 폴더로 방치하지 말고 프로그램에서 `해당 없음`으로 확정한다.
- 제작 중 PPTX와 완성 결과물은 `90.작업중`, `99.최종`에만 둔다.

권장 파일명:

```text
20260408_개최보도자료_온라인.jpg
20260409_5단광고_1회차.jpg
20260530_인스타그램_최종리포트.xlsx
20260702_시상식_현장사진_01.jpg
```

## 00.입력및안내

### 필수

- 담당자 이름과 연락 가능한 내부 정보
- 보고서 작성 기준일
- 자동 추출로 확인되지 않는 내용의 입력 파일
- 프로그램이 생성한 `기본정보.csv` 또는 향후 `결과보고_입력.xlsx`

### 있으면 좋은 자료

- 주최사가 요구한 필수 표현
- 사용 금지 표현
- 보고서에서 제외해야 하는 자료 메모
- 폴더별 자료 담당자 목록

이 폴더는 원본 사업 자료보다 프로그램 입력과 안내를 보관하는 곳이다.

## 01.최종기획안

### 필수

- 승인된 최종 사업기획안 또는 사업계획서
- 최종 전체 일정표

### 기획안에 포함되면 좋은 항목

- 사업명과 회차
- 주최·주관·후원
- 사업 기간
- 사업 목적
- 공모 주제와 공모 기간
- 홍보 계획
- 심사 계획
- 시상 규모와 총상금
- 시상식 또는 결과 발표 계획

### 권장 형식

- PPTX, PDF, DOCX, HWP/HWPX
- 일정표는 XLSX도 함께 제공

여러 기획안이 있으면 기준 문서를 하나 선택할 수 있도록 파일명을 명확히 한다.

## 02.기획및디자인

### 필수

- 최종 포스터·키비주얼
- 행사 및 주최사 로고
- 최종 홍보영상 대표 이미지와 URL
- 공모요강 또는 모집 안내 이미지

### 있으면 좋은 자료

- 홈페이지 메인·상세 화면
- SNS용 카드뉴스
- 디자인 가이드, 브랜드 색상과 폰트
- 영상 썸네일
- 프로그램이 보고서에 사용할 대표 파일 표시

원본 AI·PSD보다 보고서에서 바로 사용할 PNG·JPG·PDF 최종본을 함께 둔다.

## 03.언론홍보

### 01.보도자료

- 개최 보도자료
- 마감·출품 결과 보도자료
- 시상식·결과 발표 보도자료
- 실제 게재 캡처와 기사 URL

### 02.온라인기사

- 매체명, 기사 제목, 게재일, URL
- PC 또는 모바일 전체 캡처
- 기사 목록 Excel이 있으면 함께 저장

### 03.지면기사

- 지면 전체 이미지
- 해당 기사 확대 이미지
- 신문명, 날짜, 면 정보

### 04.신문광고

- 회차별 광고 이미지
- 집행일, 규격, 매체명
- 실제 지면 또는 집행 확인서

파일명만으로 날짜를 추정하지 않도록 기사·광고 목록을 Excel로 정리하면 가장 좋다.

## 04.온라인홍보

채널별로 다음 네 종류를 모으는 것이 이상적이다.

1. 실제 노출 화면
2. 집행 기간과 횟수
3. 최종 성과 리포트
4. 게시물·캠페인 URL

### 홈페이지

- 메인·공모·수상작 페이지 캡처
- 운영 기간
- PC·모바일 방문자 수, 페이지뷰

### 공모전사이트·커뮤니티

- 사이트명과 게시 URL
- 게시일
- 노출·조회 수
- 전체 게시처 목록 Excel

### 유튜브·인스타그램·페이스북·기타 SNS

- 게시물·영상 캡처
- 게시일과 URL
- 조회·도달·노출·좋아요·댓글·공유 수
- 채널 전체 성과와 측정 기준일

### 카카오톡·SMS·뉴스레터

- 발송 화면
- 발송일과 횟수
- 대상 인원
- 성공 건수, 열람·클릭 수
- 최종 리포트

### 디지털 광고

플랫폼별로 다음을 둔다.

- 캠페인 기간
- 예산 또는 집행금액은 보고 범위일 때만
- 노출, 도달, 클릭, 조회, 참여
- 사용한 소재
- 대시보드 캡처
- XLSX·CSV·PDF 최종 리포트

`00.통합요약`에는 플랫폼별 핵심 수치를 한 표로 정리한 자료를 둔다.

## 05.오프라인홍보

### 포스터 배포

- 공식 배포처 목록 Excel
- 지역·학교·기관별 배포 사진
- 총 배포처 수와 부수
- `00.대표사진`에 보고서용 사진 10~20장

### 옥외·교통광고

- 매체명과 위치
- 집행 기간
- 수량·노선·대수
- 설치·부착 사진
- 집행 확인서 또는 결과 리포트

### 현장홍보

- 행사명, 일시, 장소
- 운영 내용
- 현장 사진과 캡션
- 참여 인원 또는 배포 수량

## 06.출품현황

### 필수

- 최종 총 출품 수
- 부문별 출품 수
- 마감 기준일

### 보고서 품질을 높이는 자료

- D-20, D-10, D-5, D-1, 마감 누적 출품 수
- 일자별 출품 추이
- 일반부·청소년부·특별부문 등 분류
- 29역숏폼왕의 플랫폼별 출품 수
- 전년도 비교가 있으면 전년도 확정값과 출처
- 최종 출품목록 Excel

캡처만 있어도 읽을 수 있지만 Excel 집계표가 가장 정확하다.

## 07.심사

### 필수

- 최종 심사기획안
- 심사 일정
- 심사 방식과 단계
- 심사위원 최종 명단
- 본심 또는 최종 심사 결과

### 있으면 좋은 자료

- 심사위원 소속·직책·프로필 사진
- 심사 기준과 배점
- 예심 진출작 목록
- 심사 현장 사진
- 실제 참석자와 변경 사항

기획안의 예정 명단과 실제 심사위원이 다르면 실제 확정 명단을 별도로 둔다.

## 08.수상작

### 담당자 직접 확정 필수

- 상격과 부문
- 수상자·감독·팀명
- 작품명
- 상금·부상·훈격
- 작품 URL
- 시놉시스
- 대표 이미지

### 권장 자료

- `수상작_입력.csv` 또는 수상작목록 Excel
- 수상작별 고해상도 대표 이미지
- 수상작 영상 링크
- 감독 표기 방식 확인

수상작별 폴더명은 다음 형식을 권장한다.

```text
01_대상_감독명_작품명
02_최우수상_감독명_작품명
```

## 09.시상식및결과발표

### 시상식이 있는 경우 필수

- 최종 시상식 기획안
- 최종 큐시트
- 일시, 장소, 사회자
- 주요 참석자
- 실제 참석 인원
- 상장·상패·배너 등 제작물
- 현장 사진

### 있으면 좋은 자료

- 좌석 배치도
- 수상 순서
- 온라인 중계 URL과 조회 수
- 리허설 및 운영 사진
- 변경된 실제 진행 내용

### 시상식이 없는 경우

- 결과 발표 페이지 캡처
- 발표일
- 수상자 안내 방식
- 상장·상금 전달 증빙

## 10.참석자및후기

### 담당자 직접 확정

- 참석 인원
- 주요 내빈
- 보고서에 사용할 현장 사진
- 사진별 캡션
- 참가자·수상자 후기
- SNS 후기 채택 여부

### 있으면 좋은 자료

- 후기 URL과 캡처
- 주최사 피드백
- 수상 소감
- 설문 결과

사진은 원본을 모두 넣고, 보고서용 후보는 별도 대표 폴더에 복사하면 가장 효율적이다.

## 11.성과및총평

### 총평 초안에 필요한 자료

- 핵심 정량 성과
- 주최사 목표 달성 내용
- 전년 대비 변화와 정확한 비교 기준
- 홍보·출품·시상식의 주요 성과
- 참가자·주최사 반응
- 운영상 특징
- 아쉬운 점과 개선 방향
- 반드시 포함하거나 피해야 할 표현

담당자는 문장 전체를 작성하지 않아도 핵심 내용을 메모 형태로 넣을 수 있다. 프로그램은 전체 확정 데이터와 메모를 이용해 1차 총평을 만들고 담당자가 승인한다.

## 12.기타자료

- 아직 분류하지 못한 자료
- 참고용 문서
- 추가 요청 자료

프로그램은 이 폴더의 파일을 자동으로 보고서에 넣지 않고 분류 후보로 제시한다.

## 90.작업중

- 프로그램이 만든 자료 점검표
- 검수용 PPTX 초안
- 담당자가 수정 중인 PPTX
- 임시 미리보기

원본 자료를 이 폴더에 두지 않는다.

## 99.최종

- 담당자가 승인한 최종 PPTX
- 최종 PDF
- 최종 점검표
- 생성기록

기존 파일을 덮어쓰지 않고 버전 번호를 붙인다.

```text
제12회_신한_29초영화제_결과보고서_최종_v001.pptx
제12회_신한_29초영화제_결과보고서_최종_v001.pdf
```

## 최소 준비 세트

시간이 부족하면 다음 자료부터 준비한다.

1. 최종 기획안과 일정표
2. 최종 포스터·로고
3. 실제 집행한 홍보 채널의 대표 캡처와 최종 성과
4. 최종 출품 집계
5. 최종 심사기획안과 심사위원 명단
6. 수상작 확정 목록·이미지·URL·시놉시스
7. 시상식 기획안·큐시트·대표 현장 사진
8. 참석 인원과 주요 내빈
9. 총평용 성과·개선점 메모
