# 신한은행 MVP 인수 기준

## 목적

기존 신한은행 자료와 확정 입력값을 사용해, 담당자가 결과보고서 초안을 더 빠르고 안전하게 만드는지 검증한다.

## 필수 시나리오

### 프로젝트 생성

- `Z:` 경로와 UNC 경로 중 하나로 신한 결과보고 폴더를 선택할 수 있다.
- 읽기 및 쓰기 권한을 구분해 표시한다.
- 기존 `최종` 폴더 파일을 원본 자료로 오인하지 않는다.

### 입력

- 프로그램에서 모든 필수 정보를 입력할 수 있다.
- 동일 정보를 Excel에서 수정하고 다시 불러올 수 있다.
- 양쪽에서 같은 값을 다르게 수정하면 충돌 화면이 나타난다.

### 자료 점검

- 임시 파일 `M.png~RF1417c4b.TMP`를 제외한다.
- 보도자료, 올콘, 5단광고, 포스터배포, 버스광고, 유튜브, 오픈채팅방, 디지털 광고 폴더를 식별한다.
- 필수 입력 누락, 출품 합계 불일치, 수상자 정보 누락을 탐지한다.
- 대량의 포스터 배포 사진에서 모든 파일을 PPT에 넣지 않고 대표 선택 대상으로 분류한다.

### 생성

- 신한 기준 템플릿의 표지와 네 개 대분류를 유지한다.
- 자료가 없는 모듈은 승인된 규칙에 따라 제외한다.
- 증빙 수가 많은 모듈은 승인된 반복 슬라이드로 확장한다.
- 수치·날짜·인명이 확정 입력값과 일치한다.
- 생성된 PPTX를 PowerPoint에서 오류 없이 열 수 있다.

### AI

- 확정된 수치만 사용해 총평 초안을 만든다.
- 담당자가 수정·승인하기 전에는 PPTX에 반영하지 않는다.
- AI 기능을 끈 상태에서도 나머지 생성 기능이 작동한다.

### 완성 확정

- 초안은 로컬에만 존재한다.
- `완성본 확정` 전에는 NAS `최종` 폴더에 쓰지 않는다.
- 확정 시 PPTX와 PDF를 생성한다.
- PPTX 슬라이드 수와 PDF 페이지 수가 같다.
- 동일 이름이 있으면 덮어쓰지 않고 새 버전을 만든다.
- NAS 저장 실패 후 재시도할 수 있다.

## 품질 목표

- 필수 사실값 오류 0건
- 원본 파일 변경 0건
- 승인 템플릿의 고정 디자인 요소 변경 0건
- 검수자가 수정해야 하는 반복 배치 작업을 기존 대비 현저히 감소
- 다른 담당자 PC에서도 개발 도구 설치 없이 실행

## 시범 운영 종료 조건

- 실제 담당자 1명 이상이 신한 프로젝트를 처음부터 완성 확정까지 수행
- 발견된 오류와 불편 사항이 기록됨
- 차단 등급 결함이 해결됨
- 운영자와 담당자가 다음 템플릿 확장에 동의함
