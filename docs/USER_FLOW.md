# 결과보고서 프로그램 사용자 흐름 설계

## 1. 권장 전체 흐름

```text
프로젝트 열기
→ 경로·행사 유형 확인
→ 자료 자동 스캔
→ 자동 추출·분류
→ 준비도 진단
→ 필요한 항목만 입력
→ 입력·자료 사전 검증
→ 보고서 구성 미리보기
→ 1차 PPTX 생성
→ 슬라이드별 검수·보완
→ 수정 PPTX 재검증
→ 완성본 확정
→ PDF 생성·NAS 저장
```

핵심 개선점은 누락 안내를 1차 PPTX 생성 뒤가 아니라 생성 전에 먼저 제공하는 것이다. 다만 자료가 불완전해도 담당자가 전체 모양을 확인하고 싶을 수 있으므로 `미완성 초안 생성`은 별도로 허용한다.

현업에서는 결과보고서 작성을 시작한 뒤 필요한 자료를 찾아오는 경우가 많으므로, 프로그램은 `자료가 모두 준비된 상태`를 전제로 하지 않는다. 프로젝트 생성과 동시에 수집함·입력 폼·해야 할 일 목록을 만들고, 자료가 들어올 때마다 준비도와 보고서 초안을 갱신한다.

## 2. 단계별 상세 설계

### 단계 1. 시작 및 프로젝트 선택

담당자는 다음 중 하나를 사용한다.

- NAS 경로 붙여넣기
- 폴더 선택
- 최근 프로젝트 다시 열기

프로그램이 즉시 확인한다.

- 경로 존재 여부
- 읽기·쓰기 권한
- NAS 연결 상태
- 기존 프로젝트 파일 존재 여부
- 기존 제작 중·최종 PPTX 존재 여부
- 다른 담당자가 작업 중인지

기본 버튼:

- `새 프로젝트로 분석`
- `기존 작업 이어서 하기`
- `읽기 전용으로 열기`

### 단계 2. 행사 유형 자동 감지와 확인

프로그램은 경로, 기존 입력 파일, 기존 결과보고서와 자료명을 분석해 다음을 제안한다.

- 29초영화제 또는 29역숏폼왕
- 연도와 회차
- 주최사·브랜드명 후보
- 기준 템플릿

담당자는 추천 결과를 확인한다. 신뢰도가 높더라도 최초 한 번은 확인한다.

### 단계 3. 자료 자동 스캔

프로그램은 제작 중 결과보고서와 기존 최종 산출물을 제외하고 자료를 분류한다.

- 확인된 홍보 채널
- 출품·심사·수상 자료
- 시상식·결과 발표 자료
- 파일 품질과 중복
- 읽지 못한 문서
- 분류되지 않은 자료

스캔 중에도 이전 결과를 볼 수 있게 하고, 다음 실행부터는 변경 파일만 다시 검사한다.

### 단계 4. 준비도 대시보드

입력 화면부터 바로 보여주지 않고 먼저 전체 준비도를 제시한다.

```text
사업개요          60%  확인 필요 4건
사업홍보          85%  누락 2건
출품·심사         20%  필수 누락 6건
수상작            0%   필수 누락 7건
시상식            40%  확인 필요 5건
총평              초안 작성 대기
```

각 항목은 다음 상태를 가진다.

- 준비 완료
- 자동 추출, 담당자 확인 필요
- 자료 누락
- 해당 없음 확인 필요
- 필수 입력 누락
- 자료 품질 부족

### 단계 5. 스마트 입력 안내

모든 입력 항목을 한꺼번에 보여주지 않고 해당 프로젝트에 필요한 질문만 제시한다.

예:

```text
홈페이지 자료를 찾지 못했습니다.
( ) 이번 사업에서 집행하지 않음
( ) 집행했으나 자료가 아직 없음
( ) 다른 폴더에 있음 [파일 연결]
```

값이 자동 추출되면 원본과 함께 표시한다.

```text
공모기간 제안: 2026.04.08~2026.05.??
근거: 개최 보도자료
[확정] [수정] [근거 파일 열기]
```

입력 순서는 다음 우선순위를 따른다.

1. 보고서 전체에 반복되는 기본정보
2. 합계와 구조를 결정하는 출품·수상 정보
3. 페이지 포함 여부를 결정하는 홍보·시상식 정보
4. 설명 문구와 캡션
5. 총평과 선택적 후기

담당자는 정보를 다음 방식 중 편한 방법으로 추가할 수 있다.

- 화면에 직접 입력
- Excel에서 입력
- 표·메일·메신저 내용을 붙여넣기
- 파일을 드래그해 연결
- NAS의 다른 파일 경로 연결
- URL 입력
- `나중에 확인`으로 할 일 등록

원본 파일을 반드시 표준 폴더로 복사할 필요는 없다. 프로그램은 외부 경로를 출처로 연결할 수 있으며, 완성 확정 전에 링크가 유효한지 검사한다. 장기 보존이 필요한 근거 자료는 담당자 확인 후 표준 폴더에 복사하는 기능을 제공한다.

### 단계 6. AI 총평·요약 초안

총평은 프로그램 시작 직후 만들지 않는다. 확정된 핵심 성과가 어느 정도 모였을 때 1차 초안을 생성해야 사실 오류가 줄어든다.

권장 시점:

- 사업 기본정보 확정
- 출품 결과 확정
- 수상 결과 확정
- 주요 홍보 성과 확정
- 시상식 또는 결과 발표 정보 확정

아직 값이 부족하면 다음처럼 표시한다.

```text
현재 자료만으로 임시 총평을 만들 수 있습니다.
미반영: 최종 출품 수, 수상작, 참석 인원
[임시 초안 생성] [자료 입력 후 생성]
```

AI 화면에는 다음을 구분한다.

- AI 1차 초안
- 사실 근거가 연결된 문장
- 확인이 필요한 표현
- 담당자 수정본
- 최종 승인본

수치가 변경되면 영향을 받는 문장을 표시하고 재생성을 제안한다.

### 단계 7. 생성 전 사전 검증

`결과보고서 작성`을 누르기 전에 다음을 보여준다.

```text
생성 예정: 64장
완료 항목: 38개
경고: 7개
필수 누락: 3개
제외 예정 모듈: 디지털 광고, 영화제 후기
```

버튼을 두 개로 분리한다.

- `완성도 높은 초안 생성`: 필수 누락 해결 후 가능
- `미완성 초안 생성`: 누락 표시와 초안 워터마크 포함

담당자는 포함·제외할 모듈과 대표 사진을 마지막으로 확인한다.

### 단계 8. 1차 PPTX 생성

프로그램은 로컬 폴더에 생성한다.

- 기존 승인 템플릿 사용
- 데이터·표·차트·이미지 자동 배치
- 반복 페이지 자동 증설
- 누락 페이지는 빈칸 대신 명확한 상태 표시
- 생성 후 PPTX를 다시 읽어 입력값과 일치하는지 검사

생성 완료 후 다음을 제공한다.

- `PowerPoint에서 열기`
- `슬라이드 검수 시작`
- `누락 항목 보완`
- `다시 생성`

### 단계 9. 슬라이드별 검수 화면

PPT 전체를 막연히 확인하게 하지 않고 프로그램이 검수 목록을 제공한다.

```text
슬라이드 4  사업개요       확인 필요: 공모 종료일
슬라이드 18 에브리타임     완료
슬라이드 31 출품 결과      경고: 부문별 합계
슬라이드 44 수상작         누락: 대표 이미지
슬라이드 58 시상식         누락: 참석 인원
```

담당자가 PowerPoint에서 직접 디자인과 문장을 수정할 수 있다. 수정본을 프로그램에 다시 연결하면 필수 숫자·날짜·인명이 삭제되거나 달라졌는지 재검사한다.

### 단계 10. 보완과 재생성

수정 유형에 따라 다르게 처리한다.

- 자료·입력값 변경: 영향을 받는 슬라이드만 재생성 후보로 표시
- 담당자의 PowerPoint 디자인 수정: 유지
- 총평 수정: 승인본으로 저장
- 대표 사진 변경: 해당 슬라이드만 갱신

MVP에서는 전체 PPTX 재생성을 우선 구현하되, 담당자 수정을 잃지 않도록 새 버전으로 만든다. 이후 부분 재생성을 지원한다.

### 단계 11. 완성본 확정

`완성본 확정` 전 최종 체크리스트:

- 필수 오류 0건
- 경고 처리 사유 기록
- 총평 승인
- 수상 결과 확인
- 슬라이드 검수 완료
- 최종 파일명과 저장 위치 확인

확정 시:

1. 로컬 최종 PPTX 보관
2. PowerPoint로 PDF 생성
3. PPTX 슬라이드 수와 PDF 페이지 수 확인
4. NAS `99.최종` 또는 기존 최종 폴더에 새 버전 저장
5. 최종 점검표와 생성기록 저장

## 3. 담당자에게 보이는 주요 버튼

버튼은 작업 순서에 따라 활성화한다.

1. `자료 스캔`
2. `필수 정보 입력`
3. `자료 점검`
4. `총평 초안 만들기`
5. `보고서 구성 확인`
6. `1차 PPTX 생성`
7. `PowerPoint에서 열기`
8. `수정본 재검증`
9. `완성본 확정`

버튼이 비활성화된 경우 이유를 바로 표시한다.

## 4. 효율을 높이는 보조 기능

### 해야 할 일 목록

프로그램이 현재 가장 중요한 다음 행동을 3~5개만 보여준다.

```text
1. 최종 출품 수 확인
2. 수상작 목록 Excel 연결
3. 시상식 큐시트 연결
4. 홈페이지 홍보 여부 선택
```

### 원본 근거 바로 열기

자동 추출값과 보고서 요소마다 근거 파일을 연결해 담당자가 한 번에 확인한다.

### 해당 없음 재사용

같은 프로젝트에서 한 번 `해당 없음`으로 확정한 항목은 반복 질문하지 않는다.

### 변경 영향 표시

입력값이 바뀌면 영향을 받는 슬라이드와 총평 문장을 알려준다.

### 대표 이미지 후보

사진 수, 해상도, 방향, 중복 여부를 기준으로 후보를 제안하지만 담당자가 확정한다.

### 입력 재사용

사업계획서 또는 기존 운영 입력 파일에서 사업명·주최·주관·기간을 가져오되 새 프로젝트의 확정값으로 자동 채택하지 않는다.

### 자료 수집함

담당자가 분류하기 어려운 파일, 텍스트, URL을 먼저 넣는 임시 수집함을 제공한다. 프로그램이 보고서 항목을 추천하고 담당자가 확인하면 정식 데이터와 근거 자료로 연결한다.

```text
받은 자료: 시상식 큐시트.xlsx
추천 분류: 시상식 > 큐시트
[확정] [다른 항목 선택] [나중에 분류]
```

### 작성 중 질문 목록

누락 항목을 단순 경고로만 표시하지 않고 실제로 물어볼 질문으로 변환한다.

```text
- 최종 출품작 수는 몇 편인가요?
- 심사위원 최종 명단을 받을 사람은 누구인가요?
- 시상식 참석 인원은 확정됐나요?
```

각 질문에는 담당자, 요청일, 예정일, 상태, 답변과 근거를 기록할 수 있다.

### 붙여넣기 분석

메일이나 메신저로 받은 내용을 붙여넣으면 사업 기간, 수치, 인명 등의 입력 후보를 추출한다. 추출값은 담당자 확인 전까지 확정값으로 사용하지 않는다.

### 점진적 초안

준비된 영역부터 미리 생성하거나 미리보기할 수 있다. 새 자료가 들어오면 영향을 받는 페이지와 총평만 갱신 대상으로 표시한다.

## 5. 피해야 할 흐름

- 자료 스캔 전에 긴 입력 양식부터 작성하게 하기
- 모든 사업에 동일한 질문을 전부 표시하기
- PPT를 만든 뒤에야 필수 누락을 처음 알리기
- 자료가 없는데 임의 내용으로 빈칸을 채우기
- AI 총평을 사실 데이터 확정 전에 최종 문장처럼 표시하기
- PPT를 다시 생성하면서 담당자의 수동 수정본을 덮어쓰기
- NAS에 초안을 바로 저장해 최종본과 혼동하게 하기

## 6. 추천 기본 모드

프로그램은 두 가지 모드를 제공한다.

### 안내형 모드

처음 사용하는 담당자용. 프로그램이 단계별로 다음 행동을 안내한다.

### 빠른 모드

숙련 담당자용. 경로를 입력하면 스캔·자동 추출·검증을 연속 실행하고 대시보드로 바로 이동한다.

두 모드는 같은 데이터와 검증 규칙을 사용하며 화면 안내 수준만 다르다.
