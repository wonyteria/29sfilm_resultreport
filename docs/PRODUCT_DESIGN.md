# 29초영화제 결과보고서 프로그램 설계서

문서 상태: 초안 v0.2
작성일: 2026-07-13

## 1. 제품 목표

담당자가 사업별 결과보고 자료를 NAS 폴더에 모으고 주요 정보를 입력하면, 프로그램이 자료의 누락·불일치·품질 문제를 점검하고 기존 29초영화제 결과보고서 형식을 유지한 편집 가능한 PPTX 초안을 생성한다.

대상 행사는 매년 여러 주최사와 함께 진행하는 `29초영화제` 및 `29역숏폼왕`이다. 행사 유형, 주최사 브랜드, 연도와 회차가 달라져도 공통 생성 엔진을 사용하고 템플릿·페이지 구성·검증 규칙만 선택적으로 적용한다.

핵심 원칙은 다음과 같다.

1. 숫자, 날짜, 인명, 수상 결과를 추측하지 않는다.
2. 기존 승인 PPTX의 디자인과 페이지 유형을 재사용한다.
3. 자동 추출 값과 담당자 확정 값을 구분한다.
4. 최종 저장 전 반드시 사람의 확인 단계를 둔다.
5. 원본 자료와 기존 최종본을 덮어쓰지 않는다.
6. 프로그램 없이도 엑셀과 PowerPoint에서 자료를 확인·수정할 수 있게 한다.

## 2. 대상 사용자

### 주 사용자

- 29초영화제 결과보고서 작성 담당자
- PowerPoint 사용 경험은 있으나 개발 지식은 없는 사용자
- Windows PC와 NAS `Z:` 드라이브를 사용

### 관리자

- 템플릿, 검증 규칙, 프로그램 버전을 관리하는 운영자
- 신규 주최사 템플릿과 선택 페이지를 등록

## 3. 현재 보고서 분석 결과

분석 대상은 5개 보고서, 총 310개 슬라이드다.

| 보고서 | 슬라이드 | 사진 | 표 | 차트 |
|---|---:|---:|---:|---:|
| 새턴바스 | 40 | 97 | 17 | 1 |
| 서울 | 59 | 168 | 22 | 1 |
| 신한 | 88 | 291 | 32 | 1 |
| 박카스 | 67 | 185 | 22 | 1 |
| 자원순환보증금제 | 56 | 109 | 25 | 1 |

공통 대분류는 사업개요, 사업홍보, 공모·심사 또는 출품결과, 시상식이다. 보고서 간 차이는 브랜드 테마, 홍보 채널, 반복 증빙 페이지 수, 출품·심사 구조, 수상작 수, 시상식 운영 항목이다.

추가 분석한 `간단요리사 29역숏폼왕` 보고서는 33장, 미디어 81개이며 `사업개요 → 사업홍보 → 출품결과`의 3개 장 구조다. 29초영화제와 달리 시상식 장이 기본이 아니고 플랫폼별 출품 수, 세로형 수상작, 결과 발표와 상장이 중심이다.

## 4. 제품 범위

### MVP에 포함

- 사업 결과보고 폴더 선택
- NAS 연결 및 읽기·쓰기 권한 확인
- 프로젝트 기본정보 입력과 임시 저장
- 일정, 홍보 실적, 출품, 심사, 수상작, 시상식, 총평 입력
- 엑셀 가져오기·내보내기
- 폴더와 파일 자동 목록화
- 임시·중복·손상·저해상도 파일 탐지
- 필수 자료 누락 및 값 불일치 점검
- 기존 템플릿 선택
- PPTX 초안 생성
- AI 기반 총평·요약문 초안과 담당자 승인
- 생성 전후 검증 보고서 생성
- 버전이 포함된 파일명으로 `최종` 폴더 저장
- `완성본 확정` 시 PowerPoint를 이용한 PDF 자동 생성

### MVP 이후

- 이미지 유사도 기반 대표 사진 추천
- OCR을 이용한 대시보드 실적 수치 제안
- PowerPoint 자동 PDF 변환
- 신규 템플릿 등록 도구
- 작업 이력 비교와 이전 버전 복원
- 신호 파일 또는 예약 작업 기반 반자동 처리

### 제외

- 담당자 확인 없이 숫자나 사실을 생성하는 기능
- 승인되지 않은 신규 디자인 자동 생성
- 여러 사용자가 같은 프로젝트 입력값을 동시에 편집하는 실시간 협업
- 원본 자료 파일의 이동·삭제·이름 변경

## 5. 사용자 작업 흐름

1. 프로그램 실행
2. 사업의 `06.결과보고` 폴더 선택
3. 프로그램이 NAS 연결, 권한, 기존 입력 파일, 자료 폴더를 확인
4. 기존 `결과보고_입력.xlsx`가 있으면 불러오고, 없으면 새 프로젝트 생성
5. 자료 스캔 결과와 자동 추출 제안을 표시
6. 담당자가 주요 정보를 입력하거나 확정
7. `자료 점검` 실행
8. 필수 누락은 수정하고, 선택 누락은 `해당 없음` 또는 `초안 생성 허용` 처리
9. 기준 템플릿과 포함할 페이지를 확인
10. 로컬 임시 폴더에서 PPTX 생성
11. 생성 파일의 슬라이드 수, 필수 텍스트, 이미지 연결, 표 합계를 검증
12. 담당자가 PowerPoint에서 초안을 검수
13. `완성본 확정` 실행
14. PowerPoint로 PDF 변환 및 결과 검증
15. 승인된 PPTX·PDF·생성기록을 NAS `최종` 폴더에 함께 저장

상세 화면 흐름과 버튼 활성화 규칙은 `USER_FLOW.md`를 따른다. 누락은 PPTX 생성 전에 먼저 안내하고, 담당자가 전체 구성을 미리 확인할 필요가 있을 때만 `미완성 초안 생성`을 허용한다.

### 6.1 시작 화면

- 최근 프로젝트
- 프로젝트 폴더 선택
- 새 프로젝트 만들기
- 프로그램·템플릿 버전 표시
- 경로와 자료를 바탕으로 감지한 행사 유형 및 신뢰도
- `29초영화제` 또는 `29역숏폼왕` 담당자 확인

### 6.2 프로젝트 대시보드

- 자료 준비율
- 필수 누락 수
- 확인 필요 수
- 선택 자료 수
- 마지막 스캔·저장·생성 시간
- `자료 스캔`, `입력`, `점검`, `PPT 생성` 주요 버튼

### 6.3 입력 화면

왼쪽 메뉴:

1. 사업 기본정보

3. 홍보 채널과 실적
4. 출품 현황

6. 수상자·수상작
7. 시상식·큐시트

- 담당자 승인 전 PPTX 반영 금지

## 8. 저장 파일

프로젝트 폴더에 다음 파일을 사용한다.

```text
06.결과보고
├─ 결과보고_입력.xlsx
├─ 결과보고_프로젝트.json
├─ 자료점검표.xlsx
├─ 각종 자료 폴더
└─ 최종
   ├─ [사업명]_결과보고서_초안_v001.pptx
   ├─ [사업명]_결과보고서_최종_v001.pptx
   ├─ [사업명]_결과보고서_최종_v001.pdf
   └─ 생성기록
      └─ 20260713_153000.json
```

엑셀은 사람이 수정할 수 있는 기준 입력 파일이고 JSON은 프로그램 상태, 파일 연결, 템플릿 버전과 검증 이력을 저장한다.

## 9. 검증 규칙

### 차단 오류

- 사업명, 주최, 핵심 기간 미입력
- 총 출품 수와 부문별 합계 불일치
- 수상작의 상명·작품명·수상자 누락
- 같은 상이 허용 수보다 많이 입력됨
- 출력 폴더 쓰기 권한 없음
- 템플릿 파일 손상 또는 버전 불일치

### 경고

- 증빙이 없는 홍보 실적
- 대시보드 자동 추출값과 확정값 불일치
- 시상식 사진 또는 캡션 부족
- 수상작 이미지·시놉시스·URL 누락
- 이미지 해상도 부족
- 일정 중복 또는 역전
- 총평 미승인

### 정보

- 임시 파일과 숨김 파일 제외
- 유사 이미지 다수 발견
- 선택 페이지에 사용할 자료 없음

## 10. PPTX 생성 원칙

- 승인된 기존 PPTX를 템플릿 라이브러리로 사용한다.
- 슬라이드를 새로 디자인하지 않고 승인된 페이지 유형을 복제한다.
- 텍스트 상자, 표, 그림 자리에는 고유한 템플릿 키를 부여한다.
- 반복 항목 수에 따라 승인된 반복 슬라이드를 증설한다.
- 글자 수 초과 시 정해진 대체 레이아웃을 사용하며 무제한 글자 축소를 금지한다.
- 이미지는 자리 비율에 맞게 중앙 크롭하고 원본을 변경하지 않는다.
- 링크, 차트 데이터, 페이지 번호를 생성 후 재검증한다.
- 프로그램이 수정한 도형과 원본 고정 도형을 구분한다.

## 11. 기술 구조 제안

### 데스크톱 앱

- Windows 전용
- Python 기반 데스크톱 앱을 단일 실행 파일로 패키징하는 방안을 우선 검토
- UI 후보: PySide6
- 입력·검증: Python 데이터 모델 및 규칙 엔진
- Excel: openpyxl
- PPTX: python-pptx와 OOXML 직접 편집의 혼합
- PDF: 설치된 Microsoft PowerPoint 자동화를 선택 기능으로 사용
- AI 문장 작성: OpenAI API 연동을 기본 후보로 하되 회사 계정·보안·비용 정책 확정 후 인증 방식을 결정

단순 `python-pptx`만으로는 기존 슬라이드의 모든 기능과 디자인을 온전히 복제하기 어렵다. 템플릿 슬라이드 복제, 관계 파일, 차트, 하이퍼링크 보존을 위해 OOXML 계층을 별도로 설계한다.

Microsoft PowerPoint를 기본 렌더링·PDF 변환 엔진으로 사용한다. Google Slides는 기존 PPTX의 글꼴, 표, 차트, 자르기, 링크와 배치를 다르게 해석할 수 있으므로 MVP의 자동 대체 엔진으로 사용하지 않는다. PowerPoint가 없는 환경을 지원해야 할 때 별도 호환성 시험을 거쳐 제한적 대체 수단으로 추가한다.

### 실행 위치

- 프로그램은 담당자 PC 로컬에 설치
- 자료, 템플릿과 결과물은 NAS에 저장
- 대용량 이미지 처리는 로컬 임시 폴더에서 수행 후 결과만 NAS에 기록
- `Z:` 문자와 UNC 경로를 모두 지원

## 12. 동시 작업과 안전장치

- 프로젝트를 열 때 `작성중.lock` 생성
- 잠금 파일에 사용자, PC, 시작 시각 기록
- 오래된 잠금은 강제 해제 전 사용자 확인
- 입력 파일 저장 시 임시 파일에 먼저 쓴 후 원자적으로 교체
- 원본 PPTX와 자료를 덮어쓰거나 삭제하지 않음
- 최종 저장은 명시적인 승인 버튼을 통해서만 수행
- 모든 생성 작업에 로그와 입력 데이터 해시 기록

## 13. Codex 연계

MVP 생성기는 Codex 없이도 동작해야 한다. Codex는 다음 보조 작업에 사용할 수 있다.

- 비정형 자료의 의미 파악
- 누락과 충돌에 대한 설명
- 총평·요약 문장 초안
- 신규 자료 폴더의 분류 제안
- 템플릿 추가와 검증 규칙 유지보수

AI가 제안한 값과 문장은 `자동 추출` 또는 `확인 필요` 상태로만 저장하고 담당자 승인 전 최종본에 사용하지 않는다. 독립 프로그램은 Codex 로그인 세션을 직접 재사용하지 않는다. 첫 버전에서 AI 기능을 제공하려면 별도의 API 인증 방식 또는 Codex를 통한 외부 작업 흐름 중 하나를 확정해야 한다.

## 14. MVP 성공 기준

신한은행 기존 프로젝트 자료와 입력값을 사용해 다음을 만족해야 한다.

1. 기존 보고서의 대분류와 페이지 순서를 유지한다.
2. 승인 템플릿과 비교해 주요 고정 요소의 위치·스타일 차이가 없다.
3. 확정된 숫자, 날짜, 인명과 생성 결과가 일치한다.
4. 입력값이 빠지거나 합계가 틀리면 정해진 오류가 검출된다.
5. 원본 파일을 변경하지 않는다.
6. 담당자 PC에서 개발 환경 없이 실행된다.
7. 초안 생성부터 NAS 저장까지 작업 이력이 남는다.

## 15. 구현 단계

### 1단계: 설계 검증

- 담당자 인터뷰와 실제 작성 순서 확인
- 입력 항목과 필수·선택 구분 확정
- 신한 보고서 페이지 유형 분류
- 템플릿 키 명명 규칙 확정

### 2단계: 자료 점검 MVP

- 프로젝트 선택 및 스캔
- 기본정보 입력
- Excel 저장
- 누락·불일치 검증
- 점검표 생성

### 3단계: 신한 PPT 생성 MVP

- 신한 템플릿 변환
- 핵심 페이지 자동 생성
- 이미지 배치 및 반복 페이지
- 생성 결과 검증

### 4단계: 전체 템플릿 확장

- 서울, 박카스, 새턴바스, 자원순환보증금제 적용
- 선택 페이지 라이브러리 확장

### 5단계: 배포와 운영

- 단일 실행 파일 및 설치 프로그램
- 다른 담당자 PC 시범 운영
- NAS 업데이트·백업·복구 절차
- 사용자 매뉴얼과 관리자 매뉴얼

## 16. 설계 확정이 필요한 항목

- 담당자 PC별 Windows 및 Microsoft Office 정확한 버전
- NAS의 실제 UNC 경로
- AI 기능의 API 인증·비용 부담·데이터 전송 허용 범위
- 회사 보안 정책상 설치 파일 및 외부 API 사용 가능 여부
- 29역숏폼왕의 대표 결과보고서와 원본 자료 제공 시점

## 17. 확정된 제품 결정

- 담당자 PC에는 Microsoft PowerPoint가 설치되어 있다.
- PowerPoint를 MVP의 기준 렌더링 엔진으로 사용한다.
- `완성본 확정` 버튼을 누를 때 PDF를 자동 생성한다.
- 신한은행 결과보고서를 첫 번째 MVP 기준 템플릿으로 사용한다.
- 초안은 로컬에서 생성하고, 담당자 승인 후에만 NAS `최종` 폴더에 저장한다.
- AI 총평·요약문 초안을 첫 버전에 포함한다.
- 프로그램 화면과 `결과보고_입력.xlsx` 양쪽에서 데이터를 수정할 수 있게 한다.
- 데이터 충돌 시 변경 시각만으로 자동 승자 결정하지 않고 담당자에게 비교 화면을 제공한다.
- 담당자는 먼저 사업 폴더 경로를 붙여넣거나 선택한다.
- 프로그램은 경로, 기존 PPTX, 입력 파일과 자료 특징으로 행사 유형을 자동 감지한다.
- 자동 감지 결과는 담당자가 한 번 확인하며, 낮은 신뢰도 또는 충돌 시 직접 선택하게 한다.
