# 결과보고 자료 표준 폴더 규칙

## 1. 목적

담당자가 자료를 찾고 프로그램이 자동 분류하기 쉬운 공통 폴더 구조를 정의한다. 29초영화제와 29역숏폼왕은 같은 최상위 구조를 사용하되, 해당하지 않는 폴더는 만들지 않거나 `해당없음.txt`로 표시할 수 있다.

프로그램은 기존 사업의 폴더명을 그대로 읽을 수 있어야 하며, 신규 사업부터 표준 폴더 사용을 권장한다. 기존 폴더를 자동으로 이동하거나 이름을 바꾸지 않는다.

## 2. 권장 구조

```text
06.결과보고
├─ 00.입력및안내
├─ 01.최종기획안
├─ 02.기획및디자인
├─ 03.언론홍보
├─ 04.온라인홍보
├─ 05.오프라인홍보
├─ 06.출품현황
├─ 07.심사
├─ 08.수상작
├─ 09.시상식및결과발표
├─ 10.참석자및후기
├─ 11.성과및총평
├─ 12.기타자료
├─ 90.작업중
└─ 99.최종
```

숫자 접두사는 정렬과 자동 인식을 위해 사용한다. `99.최종`은 원본 자료 스캔 대상에서 기본 제외한다.

## 3. 폴더별 내용

### 00.입력및안내

```text
결과보고_입력.xlsx
담당자 확정 메모
폴더별 자료 준비 안내서
```

프로그램이 추출하지 못했거나 담당자가 직접 확정해야 하는 기준 사실값을 둔다.

### 01.최종기획안

```text
최종 사업기획안.pptx 또는 pdf
최종 사업계획서.docx 또는 hwpx
최종 일정표.xlsx
계약·과업 범위 참고자료
```

프로그램은 사업명, 회차, 주최·주관, 사업 기간, 목적, 주제, 공모 기간, 주요 일정과 시상 계획을 추출해 입력 후보로 제안한다. 문서의 `최종`, `승인`, 버전과 수정일을 확인하고 여러 파일이 있으면 담당자에게 기준 문서를 선택하게 한다. 개인정보나 계약 금액처럼 결과보고서에 필요하지 않은 정보는 추출·전송 대상에서 제외한다.

### 02.기획및디자인

```text
포스터
키비주얼
홍보영상
홈페이지 화면
공모요강
```

원본과 최종본이 섞일 경우 `01.원본`, `02.최종` 하위 폴더를 사용할 수 있다.

### 03.언론홍보

```text
01.보도자료
02.온라인기사
03.지면기사
04.신문광고
```

파일명에 날짜와 회차를 포함하는 것을 권장한다.

```text
20260410_개최보도자료.jpg
20260627_시상식기사.jpg
20260415_5단광고_1회차.jpg
```

### 04.온라인홍보

```text
01.홈페이지
02.공모전사이트
03.커뮤니티
04.유튜브
05.인스타그램
06.페이스북
07.카카오톡
08.SMS
09.뉴스레터
10.디지털광고
11.오픈채팅방
12.기타SNS
```

디지털 광고 하위에는 플랫폼별 증빙과 실적 요약을 둔다.

```text
10.디지털광고
├─ 00.통합요약
├─ 01.구글
├─ 02.카카오
├─ 03.메타
└─ 04.네이버
```

광고 플랫폼별 폴더에는 가능하면 대시보드 캡처와 함께 원본 리포트 XLSX·CSV·PDF를 둔다. 프로그램은 구조화된 리포트를 우선 사용하고 캡처 OCR은 보조 수단으로만 사용한다.

### 05.오프라인홍보

```text
01.포스터배포
02.옥외광고
03.교통광고
04.현장홍보
05.기타
```

포스터 배포는 지역·학교별 수많은 사진을 모두 사용하지 않고 대표 사진과 배포 목록을 함께 둔다.

```text
01.포스터배포
├─ 배포목록.xlsx
├─ 00.대표사진
├─ 서울
├─ 경기
└─ 기타지역
```

`00.대표사진`이 있으면 프로그램은 이를 우선 사용하고, 없으면 전체 사진에서 후보를 제안한다.

### 06.출품현황

```text
최종출품목록.xlsx
일자별출품현황.xlsx
부문별집계.xlsx
플랫폼별집계.xlsx
출품차트 참고자료
출품현황 캡처
```

29초영화제는 부문별 집계를, 29역숏폼왕은 플랫폼별 집계를 추가로 사용할 수 있다. 총합과 세부 합계가 일치해야 한다.

출품현황이 캡처만 있는 경우 프로그램이 수치 후보를 읽어 표로 제안하고 담당자가 최종 합계를 확인한다.

### 07.심사

```text
심사계획
최종 심사기획안
심사위원명단.xlsx
심사기준
예심결과
본심결과
심사현장사진
```

29역숏폼왕에서 심사 과정이 보고서에 표시되지 않더라도 수상 결과 검증을 위한 원본 자료로 사용할 수 있다.

### 08.수상작

```text
수상작목록.xlsx
대표이미지
시놉시스
영상URL
상금및훈격
```

수상작별 하위 폴더가 필요하면 다음 형식을 권장한다.

```text
01_대상_감독명_작품명
02_최우수상_감독명_작품명
```

수상자와 수상작은 사람의 확인이 필요한 핵심 사실이므로 프로그램 화면 또는 `결과보고_입력.xlsx`에서 담당자가 직접 확정한다. 자료 폴더는 대표 이미지·시놉시스·영상 URL 등의 근거 연결에 사용한다.

### 09.시상식및결과발표

```text
01.행사개요
00.최종시상식기획안
02.큐시트
03.참석자
04.제작물
05.현장사진
06.온라인중계
07.결과발표
```

29역숏폼왕처럼 별도 시상식이 없으면 `07.결과발표`만 사용할 수 있다.

프로그램은 시상식 기획안에서 일시, 장소, 사회자, 진행 순서, 제작물과 온라인 중계 정보를 제안한다. 실제 참석 인원과 변경된 현장 운영 내용은 담당자가 확정한다.

### 10.참석자및후기

```text
참석자수및주요내빈.xlsx
현장사진
사진캡션.xlsx
참가자후기
수상자후기
SNS후기
주최사피드백
```

참석 인원, 주요 내빈과 후기의 채택 여부는 담당자가 직접 확정한다. 현장 사진은 프로그램이 품질·중복 기준으로 후보를 제안한다.

### 11.성과및총평

```text
통합성과.xlsx
총평메모
```

프로그램은 확정된 사업 목적, 출품, 홍보, 수상, 시상식, 후기 데이터를 바탕으로 총평 1차 초안을 작성한다. 담당자가 수정·승인해야 보고서에 반영한다.

### 12.기타자료

분류가 확정되지 않은 참고 자료를 둔다. 프로그램은 이 폴더의 파일을 자동으로 최종본에 넣지 않고 분류 후보로만 제시한다.

### 90.작업중

프로그램의 임시 산출물, 담당자 검수용 초안과 점검표를 둔다. NAS가 느릴 경우 실제 대용량 작업은 PC 로컬 임시 폴더에서 수행한다.

### 99.최종

승인된 PPTX, PDF, 생성기록과 최종 점검표만 둔다.

```text
[사업명]_결과보고서_최종_v001.pptx
[사업명]_결과보고서_최종_v001.pdf
생성기록_20260713_153000.json
최종점검표_20260713.xlsx
```

## 4. 기존 폴더명 자동 매핑

프로그램은 다음 별칭을 표준 폴더로 해석한다.

| 기존 명칭 예시 | 표준 분류 |
|---|---|
| 보도자료 | 02.언론홍보/01.보도자료 |
| 5단광고, 신문광고 | 02.언론홍보/04.신문광고 |
| 올콘 | 03.온라인홍보/02.공모전사이트 |
| 인스타 | 03.온라인홍보/05.인스타그램 |
| 카카오톡 광고메시지 | 03.온라인홍보/07.카카오톡 |
| 스티비 | 03.온라인홍보/09.뉴스레터 |
| 광고(구글, 카카오, 인스타, 네이버) | 03.온라인홍보/10.디지털광고 |
| 포스터배포 | 04.오프라인홍보/01.포스터배포 |
| 버스광고 | 04.오프라인홍보/03.교통광고 |
| 최종, 00.결과보고서 | 99.최종 |

별칭 사전은 관리자 설정에서 확장할 수 있다.

## 5. 담당자 최소 준비 항목

모든 폴더를 채울 필요는 없다. 최소 준비 항목은 다음이다.

1. `01.최종기획안`의 승인된 최종 문서
2. 실제 집행한 홍보 채널의 증빙과 가능하면 원본 실적 리포트
3. `06.출품현황`의 최종 집계 또는 캡처
4. `07.심사`의 최종 심사기획안과 확정 결과
5. `08.수상작`의 수상자·작품·URL·이미지
6. 시상식이 있으면 `09.시상식및결과발표`의 최종 기획안과 큐시트
7. `10.참석자및후기`의 현장 자료와 담당자 확정 정보
8. `11.성과및총평`의 총평용 메모

프로그램은 비어 있는 폴더와 아예 존재하지 않는 폴더를 구분한다. 해당 활동을 하지 않았다면 `해당 없음`으로 확정하고, 자료를 아직 받지 못했다면 `누락`으로 표시한다.

## 6. 경로 입력 방식

담당자는 프로그램에 사업 폴더 경로를 붙여넣거나 폴더 선택 버튼을 사용한다.

```text
Z:\2026\03.진행사업\02.29역숏폼왕\...\06.결과보고
```

프로그램은 경로만으로 다음을 제안한다.

- 행사 유형
- 연도
- 주최사 또는 사업명 후보
- 결과보고 폴더
- 기존 최종본과 사용할 템플릿 후보

담당자가 추천 내용을 확인하면 프로젝트를 생성한다. 따라서 매번 처음부터 행사 유형을 수동 선택할 필요는 없지만, 잘못된 템플릿 생성을 막기 위해 최초 확인 단계는 유지한다.
