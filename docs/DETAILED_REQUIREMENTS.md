# 상세 기능 요구사항

## 1. 프로젝트 생애주기

프로젝트 상태는 다음 순서로 관리한다.

```text
신규 → 자료수집중 → 점검필요 → 입력확정 → 초안생성 → 검수중 → 완성확정 → 보관
```

- `자료수집중`: 자료가 계속 추가될 수 있다.
- `점검필요`: 스캔 이후 미해결 오류가 있다.
- `입력확정`: 필수 입력값이 담당자에 의해 확정됐다.
- `초안생성`: 로컬 PPTX가 생성됐다.
- `검수중`: 담당자가 PowerPoint에서 수정하고 있다.
- `완성확정`: PPTX와 PDF를 NAS에 저장했다.
- `보관`: 수정이 필요할 경우 새 버전을 만들어야 한다.

완성확정 이후 입력값이나 자료가 바뀌면 기존 완성본을 변경하지 않고 새 개정 버전을 만든다.

프로젝트 생성 시 자료가 완비되어 있을 필요는 없다. `자료수집중` 상태에서 담당자는 프로그램을 자료 수집 체크리스트와 작성 작업 공간으로 사용한다.

## 2. 데이터의 출처와 우선순위

값마다 출처를 기록한다.

1. 담당자 확정값
2. 프로그램 화면 입력값
3. Excel 입력값
4. 구조화된 원본 문서에서 추출한 값
5. 이미지 OCR 또는 AI 제안값
6. 이전 보고서 참고값

상위 값이 항상 자동으로 하위 값을 덮어쓰는 것은 아니다. 서로 다른 값이 발견되면 비교 화면에서 담당자가 하나를 확정한다. 이전 보고서의 값은 절대 새 프로젝트의 사실로 자동 채택하지 않는다.

## 3. 화면과 Excel 양방향 동기화

- 프로그램 시작 시 Excel 파일의 수정 시각과 내부 데이터 버전을 확인한다.
- 프로그램 저장 시 먼저 프로젝트 JSON을 안전하게 저장하고 Excel을 갱신한다.
- 프로그램이 닫힌 동안 Excel이 수정되었으면 다음 실행 시 변경 행을 비교한다.
- 같은 필드가 양쪽에서 변경되었으면 충돌로 표시한다.
- Excel의 시트명, 열 이름, ID 열은 보호한다.
- 사람이 추가하는 메모 열은 보존한다.
- 날짜, 숫자, URL, 파일 경로의 형식을 검증한다.

권장 Excel 시트:

1. 안내
2. 기본정보
3. 전체일정
4. 홍보실적
5. 출품현황
6. 심사정보
7. 수상작
8. 시상식
9. 참석자후기
10. 총평
11. 파일연결
12. 검증결과

### 비정형 입력

프로그램은 결과보고서 작성 중 새로 확보한 정보를 다음 형태로 받을 수 있어야 한다.

- 일반 텍스트 붙여넣기
- 표 붙여넣기
- 파일 첨부 또는 경로 연결
- 웹 URL
- 담당자 메모
- Excel 가져오기

각 값은 `값`, `출처`, `확정 상태`, `확정자`, `확정 시각`을 가진다. 출처가 없는 수동 입력도 허용하지만 완성 확정 전 담당자 확인을 요구한다.

## 4. 자료 스캔

### 인식 대상

- 이미지: JPG, JPEG, PNG, WEBP, TIFF
- 문서: PPTX, PDF, XLSX, DOCX, HWP/HWPX는 지원 가능성 별도 검증
- 영상: MP4, MOV의 메타데이터와 대표 이미지
- 링크: Excel 또는 입력 화면의 URL

### 제외 대상

- `~$`로 시작하는 Office 임시 파일
- `.tmp`, `.bak`, 숨김 파일
- 결과물 생성 폴더 내부의 이전 산출물
- 크기가 0인 파일
- 사용자가 제외 표시한 파일

### 파일 품질 검사

- 파일 열기 가능 여부
- 이미지 픽셀 크기와 종횡비
- 중복 해시
- 동일·유사 파일 후보
- 파일명에 포함된 날짜와 입력 일정의 불일치
- 너무 긴 경로와 지원하지 않는 문자

## 5. 필수 입력 규칙

### 모든 행사 공통

- 사업명, 회차, 행사 유형
- 주최·주관
- 사업 기간과 공모 기간
- 목적, 주제
- 총 출품 수와 부문별 수치
- 심사 일정과 방식
- 수상 결과
- 시상식 또는 결과 발표 정보
- 보고서 기준일

### 조건부 필수

- 오프라인 시상식이 있으면 장소, 사회자, 큐시트, 현장 사진
- 상금이 있으면 상별 상금과 총상금
- 유료 광고가 있으면 집행 기간과 확정 성과
- SNS 성과를 보고하면 채널별 기준일과 측정 단위
- 전년 대비를 표시하면 전년도 기준값과 출처

## 6. 검증 등급

### 오류

완성본 확정을 차단한다. 초안 생성은 관리자 설정에 따라 워터마크와 함께 허용할 수 있다.

### 경고

담당자가 사유를 입력하고 승인하면 진행할 수 있다.

### 안내

생성을 막지 않으며 개선을 제안한다.

모든 오류와 경고는 `규칙 ID`, 설명, 현재 값, 기대 값, 출처 파일, 해결 상태, 처리자, 처리 시각을 기록한다.

## 7. 템플릿 선택

템플릿은 다음 축을 분리한다.

- 행사 유형: 29초영화제 / 29역숏폼왕
- 브랜드 테마: 주최사별 색상·로고·표지
- 콘텐츠 모듈: 보도자료, 지면광고, 포스터 배포, 디지털 광고, 출품, 심사, 수상작, 시상식, 후기
- 출력 규칙: 슬라이드 순서, 반복 단위, 최대 항목 수

템플릿 자동 추천 결과를 담당자가 변경할 수 있어야 한다. 프로그램은 템플릿 ID와 버전을 생성 기록에 남긴다.

### 행사 유형 자동 감지

감지 신호는 다음 우선순위로 사용한다.

1. 기존 `결과보고_프로젝트.json`의 행사 유형
2. 담당자가 선택한 사업 루트 경로의 `29초영화제`, `29역숏폼왕` 문자열
3. 기존 결과보고 PPTX의 표지·목차 텍스트
4. 입력 Excel의 행사 유형
5. 자료 특성: 세로형 숏폼 플랫폼, 시상식 자료, 심사 구조 등

프로그램은 신뢰도와 판단 근거를 표시한다. 경로와 PPTX가 서로 다른 유형을 가리키거나 신뢰도가 기준 이하이면 자동 확정하지 않는다. 담당자는 첫 실행에서 추천 유형을 확인하고, 확정된 유형은 프로젝트 파일에 저장된다.

### 유형별 기본 구조

| 구분 | 29초영화제 | 29역숏폼왕 |
|---|---|---|
| 기본 대분류 | 사업개요, 사업홍보, 공모·심사/출품결과, 시상식 | 사업개요, 사업홍보, 출품결과 |
| 출품 구분 | 일반부·청소년부 등 부문 중심 | 유튜브·인스타그램 등 플랫폼 중심 가능 |
| 영상 형식 | 29초 중심 | 세로형 숏폼, 1분 이내 등 프로젝트별 규칙 |
| 시상식 | 일반적으로 포함, 없으면 제외 | 선택 항목 |
| 수상작 | 부문·상격·시놉시스 | 상격·플랫폼 URL·세로형 대표 이미지 |
| 결과 운영 | 시상식과 현장 운영 포함 가능 | 온라인 결과 발표·상장 중심 가능 |

## 8. 초안 생성

- 로컬 작업 폴더에 먼저 생성한다.
- 파일명에 `초안`, 버전, 생성 시각을 포함한다.
- 미해결 경고가 있으면 첫 슬라이드 메모 또는 별도 점검표에 기록한다.
- 초안 PPTX의 필수 텍스트와 수치가 입력 데이터와 일치하는지 재추출해 검사한다.
- PowerPoint로 열 수 있는지 확인한다.

## 9. PowerPoint 검수와 재가져오기

담당자가 생성된 PPTX를 직접 수정할 수 있다. 프로그램은 수정된 PPTX를 다시 선택해 완성본으로 확정할 수 있어야 한다.

- 원래 자동 생성본과 담당자 수정본을 구분한다.
- 담당자 수정본을 다시 자동 생성하지 않는다.
- 완성 확정 전 필수 데이터가 PPTX에서 누락되지 않았는지 검사한다.
- 디자인 수정은 허용하되 필수 숫자·인명 삭제는 경고한다.

## 10. 완성본 확정

1. 미해결 오류 확인
2. 담당자 이름과 확정 시각 기록
3. 수정된 PPTX를 로컬 보관본으로 복사
4. Microsoft PowerPoint를 통해 PDF 생성
5. PPTX와 PDF의 페이지 수 비교
6. 파일 크기 0, 열기 실패, PDF 페이지 누락 검사
7. NAS `최종` 폴더에 임시 이름으로 업로드
8. 업로드 성공 후 최종 파일명으로 변경
9. 생성기록과 점검표 저장

NAS 저장 실패 시 로컬 완성본은 유지하고 재시도할 수 있어야 한다.

## 11. AI 문장 작성

### 입력

- 담당자가 확정한 사업 정보와 실적
- 선택한 이전 보고서의 문체 예시
- 담당자가 입력한 핵심 성과·개선점·금지 표현

### 출력

- 사업 요약
- 홍보 성과 요약
- 출품·심사 결과 요약
- 최종 총평

### 제한

- 제공되지 않은 성과나 평가를 사실처럼 쓰지 않는다.
- 숫자·날짜·인명은 구조화 데이터의 값을 그대로 사용한다.
- 비교 표현은 비교 기준이 있을 때만 사용한다.
- AI 결과는 승인 전까지 `초안` 상태다.
- 프롬프트, 모델, 입력 데이터 버전과 승인 이력을 기록한다.

## 12. 권한과 개인정보

- 프로그램은 현재 Windows 사용자의 NAS 권한만 사용한다.
- NAS 암호를 프로그램이나 설정 파일에 저장하지 않는다.
- 외부 API로 전송되는 자료 범위를 화면에 표시한다.
- 수상자 연락처 등 보고서에 필요하지 않은 개인정보는 AI로 보내지 않는다.
- 관리자 설정으로 AI 기능을 완전히 끌 수 있어야 한다.

## 13. 장애와 복구

- 프로그램 비정상 종료 후 임시 작업 복원
- Excel 손상 시 직전 백업 복원
- PowerPoint 자동화 실패 시 PPTX는 유지하고 PDF 생성만 재시도
- NAS 연결 끊김 시 로컬 대기열에 저장
- 템플릿 버전이 변경돼도 이전 프로젝트는 기존 버전으로 재생성 가능

## 14. 성능 목표

- 2,000개 파일이 있는 프로젝트의 목록 스캔: 목표 60초 이내
- 변경 파일만 다시 읽는 증분 스캔 지원
- 수백 MB의 PPTX·이미지는 로컬 임시 폴더에서 처리
- UI가 스캔·생성 중 멈추지 않도록 백그라운드 작업 사용

## 15. 감사 기록

다음 작업을 기록한다.

- 프로젝트 생성·열기
- Excel 가져오기와 충돌 해결
- 자동 추출값 승인·거부
- 오류 예외 승인
- 초안 생성
- AI 문장 생성과 승인
- 완성본 확정과 NAS 저장

기록에는 사용자, PC, 시각, 프로그램 버전, 템플릿 버전, 입력 데이터 해시를 포함한다.
